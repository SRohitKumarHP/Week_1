# Week_1
Python-OpenCV setup, Mini task — build a script that reads a folder of images, converts to grayscale, resizes, and saves output batch.

1. First, download all the codes in a separate folder along with the .jpg, .png, or ... etc files.
To run these programs, you need to install the required libraries first.
2. Open a new Terminal and First run:
   pip install opencv-python
   pip install numpy
3. After installing the required libraries, you are ready to run the code.
4. In the terminal run:
   python <file_name>
5. In the place of <file_name>, enter the required file name that you want to run, like python 12Rotate.py, python ImageShapeCV2.py, etc.
